# Работа с Кампусом

## Назначение и источники истины

Это конкурсный прототип студенческой системы с вымышленными данными. Сначала прочитайте [PRODUCT.md](PRODUCT.md), [DESIGN.md](DESIGN.md), [README.md](README.md) и текущий хвост [очереди](docs/superpowers/plans/2026-11-21-review-queue.md). Устройство и контракты описаны в [архитектуре](docs/architecture.md) и [API](docs/api.md). Указания автора важнее исторических итераций в очереди.

## Порядок работы

- Новые замечания добавляйте в конец очереди. Не стирайте историю; отмечайте выполненные пункты и фактическую проверку.
- Сохраняйте изменения пользователя. Перед работой проверьте `git status`.
- Не сбрасывайте базу ради запуска или тестов. `backend/seed.py` удаляет демо-данные, включая личный план.
- Меняйте общий компонент или активный стиль, если проблема системная. Не добавляйте зависимости для простых CSS/SVG-эффектов.
- Не утверждайте, что работа проверена, пока соответствующая команда не завершилась успешно. Не собирайте фронтенд параллельно браузерным тестам: Flask обслуживает изменяемый `dist`.
- Коммиты и push выполняйте в рамках запроса автора. Не подменяйте публичное размещение push в GitHub.

## Ограничения интерфейса

Система должна помогать студенту действовать. Не возвращайте стандартный dashboard/bento, одинаковые карточки, хлебные крошки и повтор имени/группы. Нужны собранная композиция, угловатые формы, звёзды и выборочный pop-art растр. Цвет выражает состояние, а не случайный декор. Основной шрифт — локальный Golos Text. Маленький логотип статичный. Подробности и исключения — DESIGN.md.

Не наклоняйте текст и формы ввода вместе с декором. Не обрезайте фокус clip-path. Анимации прерываемые, преимущественно transform/opacity; учитывайте reduced motion и тип указателя. Не запускайте постоянное движение без остановки.

## Данные и безопасность

Все пользовательские запросы к MongoDB ограничиваются текущим студентом либо его группой/аудиторией. Чужой объект возвращает 404. Не доверяйте user_id из тела запроса. Проверяйте JSON и значения на сервере. JWT только в HttpOnly cookie; секреты и `.env` не коммитить. Внешний ИИ получает только нужный контекст текущего демо-аккаунта и предлагает действия; запись требует явного действия студента.

Не фабрикуйте историю использования ИИ или результаты проверок. Реконструкции явно обозначайте. Не добавляйте официальный брендинг или настоящие персональные данные.

## Проверки

Из `frontend/`: `npm test`, `npm run build`, затем `npm run test:ui` при работающих Flask и MongoDB. Из корня: `PYTHONPATH=backend /path/to/venv/bin/python -m unittest discover -s backend/tests -v`. Для чисто визуальной правки достаточно сборки, существующих проверок затронутых сценариев и просмотра 360/768/1280 px; проверки безопасности обязательны при изменении API.

Браузеры: современные Chromium, Firefox, Safari; критические сценарии работают без WebGL. Новые платформенные возможности допускаются с простым fallback. Автотесты сейчас запускаются в Chromium, поэтому не заявляйте проверку других браузеров без реального прогона.
