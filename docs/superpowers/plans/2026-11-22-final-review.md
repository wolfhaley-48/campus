# Финальный конкурсный проход Implementation Plan

> **For agentic workers:** выполнить задачи по порядку; аудит безопасности и подготовка отчёта делегированы отдельным агентам. Результаты подтвердить командами перед закрытием.

**Goal:** сверить Кампус с конкурсным ТЗ, устранить подтверждённые пробелы и подготовить актуальную документацию для сдачи.

**Architecture:** сохранить существующие React/Flask/MongoDB и пользовательские изменения. Отдельно проверить исходники, локальную сборку и опубликованный экземпляр; отчёт опирается на наблюдаемые результаты, реконструкции обозначаются.

**Tech Stack:** React 19, Vite 8, Flask, MongoDB, Playwright, unittest, ReportLab.

**Spec:** исходный `task.htm`, предоставленный автором; `PRODUCT.md`, `DESIGN.md`, `AGENTS.md`.

## Global Constraints

- Не сбрасывать существующую базу и личный план.
- Только вымышленные данные; чужой объект возвращает 404.
- Не собирать frontend параллельно браузерным тестам.
- Основные сценарии на 360 px; не заявлять Safari/Firefox без реального прогона.
- Прототип доступен по ссылке из России без VPN до 28 ноября.
- Реальные логи ИИ отсутствуют; примеры прошлых диалогов — реконструкции.

## Review Focus

- Подстановка чужого ID и user_id: сервер сохраняет границы аккаунта.
- Повтор отправки и перезагрузка: данные сохраняются, дубли сообщений исключены.
- Мобильная навигация, фокус, reduced motion: сценарии остаются доступны.
- Ошибка API и провайдера ИИ: форма сохраняет ввод и позволяет повторить.
- Публичная версия и отчёт: соответствуют текущей реализации, ограничения явно указаны.
