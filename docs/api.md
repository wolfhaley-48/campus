# HTTP API

Базовый путь `/api`, JSON-ответы. Кроме health и login, данные требуют действующей сессии; logout удаляет cookie. Вход ставит HttpOnly JWT-cookie. Изменяющие запросы с чужим Origin отклоняются. Передавайте `Content-Type: application/json` для JSON-тел; массив, строка и null вместо объекта недопустимы.

| Метод | Путь | Назначение / вход |
| --- | --- | --- |
| GET | `/health` | Доступность сервера и базы |
| POST | `/auth/login` | `{login, password}`; устанавливает cookie |
| POST | `/auth/logout` | Выход |
| GET | `/auth/me` | Текущий профиль |
| GET | `/dashboard` | Сегодня, ближайшая пара, сводка, сроки |
| GET | `/schedule?week=0` | Неделя относительно текущей; расписание группы и изменения |
| GET | `/grades` | Все доступные семестры студента и сессия |
| GET | `/requests` | Заявки владельца, типы и способы получения |
| POST | `/requests` | `{type, delivery, comment}`; type/delivery из серверного справочника |
| GET | `/requests/:id` | Своя заявка с историей |
| GET | `/requests/:id/document` | PDF только своей готовой электронной справки |
| GET | `/notifications` | Видимые уведомления, непрочитанные и связанные действия |
| POST | `/notifications/:id/read` | Отметка конкретного видимого уведомления |
| POST | `/notifications/read-all` | Отметка всех видимых уведомлений |
| GET | `/plan?duration=45` | Свободные окна и сохранённые задачи |
| POST | `/plan` | `{title, duration, date, start}`; дата YYYY-MM-DD, время HH:MM из предложенного окна |
| DELETE | `/plan/:id` | Удаление своей задачи |
| POST | `/assistant` | `{query}` до 1200 символов; объяснение, действия, предложения задач |

## Ошибки и доверие

401 — сессия отсутствует/истекла; 400 — неверное тело/значение; 403 — чужой Origin; 404 — объект не существует либо недоступен студенту; 409 — окно уже занято; 429 — ограничение частоты; 503 — внешний помощник недоступен. Для конкретного сообщения клиент использует `message`, если оно есть, и сохраняет введённые данные.

PDF недоступен до готовности или при бумажном способе получения. Номер заявки не предоставляет право чтения: сервер проверяет владельца. Для плана title ограничен 120 символами, длительность выбирается из 30/45/60/90 минут, доступность проверяется повторно перед записью. Мутации не принимают доверенный user_id от браузера.

Ответ помощника содержит `answer`, `provider`, `actions`, `tasks`, если они доступны. `provider` — `DeepSeek`, `OpenRouter` или `Pollinations`; в режиме `auto` сервер выбирает DeepSeek при заданном `DEEPSEEK_API_KEY`, затем OpenRouter при заданном `OPENROUTER_API_KEY`, иначе использует резервный публичный endpoint. При ошибке внешнего провайдера `auto` делает одну попытку Pollinations. Действия ограничены серверным списком; задачи содержат название, длительность и ссылку на планировщик. Переход к задаче не сохраняет её автоматически. Внешний ответ не вставляется как HTML. В запрос к провайдеру попадают только данные текущего вымышленного аккаунта: расписание, оценки, заявки, уведомления и личный план. Личные сообщения и чужие данные не передаются.

Точные поля учебных сущностей определены в `backend/serializers.py`, допустимые типы заявок — в `backend/constants.py`, сборка ответов — в `backend/services.py`. При изменении контракта обновляйте соответствующую страницу, тесты и этот файл вместе.

Непрерывная лента расписания использует тот же GET `/schedule?week=N`. Диапазон расширен до −5200…5200 вместо прежних −8…8; каждое обращение ограничено одной неделей и группой текущего пользователя. На клиенте хранится до пяти недель, а не вся просмотренная история.

## Социалка

Все пути ниже требуют сессии. Ответы содержат только публичные для прототипа поля автора: id, имя, логин, группа. Оценки, заявки, почта и пароль в социалку не попадают.

| Метод | Путь | Контракт |
| --- | --- | --- |
| GET | `/social/feed?before=<id>` | До 10 доступных постов, `items`, `hasMore`, `nextCursor`; весь кампус или своя группа |
| POST | `/social/feed` | `{body, scope}`: 1–2000 символов, scope `group` или `all`; группа и автор определяются сервером |
| POST | `/social/feed/<post_id>/like` | `{liked}`: boolean; выставить/снять свой лайк без дублирования |
| GET | `/social/feed/<post_id>/comments?before=<id>` | До 20 комментариев доступного поста, `items`, `hasMore`, `nextCursor` |
| POST | `/social/feed/<post_id>/comments` | `{body, clientId}`: до 1000 символов, UUID; повтор своего UUID у того же поста не создаёт дубль |
| GET | `/social/threads` | Свой групповой чат и личные диалоги с демо-студентами, preview и unread |
| GET | `/social/threads/<channel>/messages` | Последние 30 сообщений в хронологическом порядке; before — старая история, after — новые сообщения |
| POST | `/social/threads/<channel>/messages` | `{body, clientId}`: до 2000 символов и UUID отправки; повтор UUID в том же диалоге от того же автора не создаёт дубль |
| POST | `/social/threads/<channel>/read` | `{lastId}`: только сообщение этого диалога; отметка чтения двигается только вперёд |

Канал `group:<группа>` разрешён только текущей группе. Канал `dm:<id1>:<id2>` содержит два существующих ID в отсортированном порядке; текущий студент должен быть одним из них. Неверный канал, чужая группа или личка возвращают 404. Произвольный user_id и группа из запроса не предоставляют прав. before и after одновременно недопустимы; некорректный курсор возвращает 400.

Поля поста `likes`, `liked`, `comments` содержат число лайков, состояние текущего студента и число комментариев. Лайки и комментарии доступны только при доступе к самому посту; чужая группа возвращает 404. Автор определяется сессией. Эти дополнительные API сохранены из пользовательских изменений; самостоятельные контролы лайков/комментариев в текущей стене не заявляются.
