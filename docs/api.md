# HTTP API

Базовый путь `/api`, JSON-ответы. Кроме health и login, данные требуют действующей сессии; logout удаляет cookie. Вход ставит HttpOnly JWT-cookie. Изменяющие запросы с чужим Origin отклоняются. Передавайте `Content-Type: application/json` для JSON-тел; массив, строка и null вместо объекта недопустимы.

| Метод | Путь | Назначение / вход |
| --- | --- | --- |
| GET | `/health` | Доступность сервера и базы |
| POST | `/auth/login` | `{login, password}`; устанавливает cookie |
| POST | `/auth/logout` | Выход |
| GET | `/auth/me` | Текущий профиль |
| GET | `/dashboard` | Сегодня, ближайшая пара, сводка, сроки |
| GET | `/schedule?week=0` | Неделя относительно текущей; расписание группы и изменения |
| GET | `/grades` | Все доступные семестры студента и сессия |
| GET | `/requests` | Заявки владельца, типы и способы получения |
| POST | `/requests` | `{type, delivery, comment}`; type/delivery из серверного справочника |
| GET | `/requests/:id` | Своя заявка с историей |
| GET | `/requests/:id/document` | PDF только своей готовой электронной справки |
| GET | `/notifications` | Видимые уведомления, непрочитанные и связанные действия |
| POST | `/notifications/:id/read` | Отметка конкретного видимого уведомления |
| POST | `/notifications/read-all` | Отметка всех видимых уведомлений |
| GET | `/plan?duration=45` | Свободные окна и сохранённые задачи |
| POST | `/plan` | `{title, duration, date, start}`; дата YYYY-MM-DD, время HH:MM из предложенного окна |
| DELETE | `/plan/:id` | Удаление своей задачи |
| POST | `/assistant` | `{query}` до 1200 символов; объяснение, действия, предложения задач |

## Ошибки и доверие

401 — сессия отсутствует/истекла; 400 — неверное тело/значение; 403 — чужой Origin; 404 — объект не существует либо недоступен студенту; 409 — окно уже занято; 429 — ограничение частоты; 503 — внешний помощник недоступен. Для конкретного сообщения клиент использует `message`, если оно есть, и сохраняет введённые данные.

PDF недоступен до готовности или при бумажном способе получения. Номер заявки не предоставляет право чтения: сервер проверяет владельца. Для плана title ограничен 120 символами, длительность выбирается из 30/45/60/90 минут, доступность проверяется повторно перед записью. Мутации не принимают доверенный user_id от браузера.

Ответ помощника содержит `answer`, `provider`, `actions`, `tasks`, если они доступны. Действия ограничены серверным списком; задачи содержат название, длительность и ссылку на планировщик. Переход к задаче не сохраняет её автоматически. Внешний ответ не вставляется как HTML.

Точные поля учебных сущностей определены в `backend/serializers.py`, допустимые типы заявок — в `backend/constants.py`, сборка ответов — в `backend/services.py`. При изменении контракта обновляйте соответствующую страницу, тесты и этот файл вместе.
