- Полный Chromium после нижнего куба и исправления фокуса: 102/102, exit 0; ширины 360/768/1280 px.
- Публичная версия: 19 проверок API и 48 экранов (8 разделов × 2 аккаунта × 3 ширины). Ошибок JavaScript и горизонтального выхода нет. Cookie `HttpOnly; Secure; SameSite=Lax`; чужие заявки — 404.
- После синхронизации HTML, основной JS, CSS и runtime публичного сайта побайтово совпали с локальной production-сборкой. Последующая локальная правка требует новой выкладки.
- Настоящие вызовы ИИ: локальный Pollinations — HTTP 200; публичный OpenRouter — HTTP 200. Один из трёх публичных ответов содержал JSON-хвост, два следующих вернули нормальные действия и задачи. Это наблюдение, не статистическая оценка модели.
- Отдельно выполнен реальный сценарий формы заявки на 360 px без подмены API: отправка кнопкой → MongoDB → обновление страницы → сохранённый комментарий; Максим получает 404. Проверочная заявка и её уведомление удалены.

Свидетельства публичного прогона: [JSON без cookie и секретов](public-smoke-results.json), скриншоты `screenshots/final-public-*`. Полные логи локального прогона сохранены в проверочном окружении; чужие/реальные данные в отчёт не включены.

## Что исправлено в этом проходе

Ответ провайдера мог быть формально допустимым JSON, но содержать поля `actionIds`/`tasks` внутри самой строки ответа. Теперь сервер отклоняет такую структуру и использует существующий резерв в режиме auto либо показывает ошибку с сохранением ввода. Две регрессии проверяют и отклонение, и резерв. Ответ не обрезается и не «ремонтируется» догадками.

Добавлены проверки: запросы без сессии; два полных профиля; scrypt и cookie; поддельный/истёкший JWT; неверный JSON и NoSQL payloads; подстановка владельца заявки; сохранение заявки в новой сессии; чужое уведомление/документ; Origin независимо от атакующего Host; production-secret; приватность и валидация, идемпотентность лайков и UUID комментариев.

Длинная свёрнутая полоса помощника заменена статичным нижним кубом. Верхний бренд сохранён; открытие переводит фокус в поле, закрытие/Escape возвращают его на куб. Ввод и ответ сохраняются.

README переписан для жюри: публичная ссылка, аккаунты, краткий маршрут демонстрации, запуск, проверки и документация. Раздел лицензий из README удалён по запросу автора, обязательная атрибуция сторонних материалов сохранена отдельно. Отчёт отражает современную реализацию, подтверждённые инструменты, ошибки ИИ и реальные скриншоты.
